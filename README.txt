صفحه اختصاصی محمدباقر بیت سخری
=================================

این فایل‌ها یک وب‌سایت آماده و واقعی هستند، اما تا زمانی که در هاست منتشر نشوند، آدرس عمومی ندارند.
بنابراین هنوز QR Code نهایی قابل ساخت نیست؛ زیرا باید به نشانی منتشرشده اشاره کند.

روش انتشار رایگان با GitHub Pages:
1) در GitHub یک مخزن عمومی جدید، مثلاً mohammadbagher-portfolio، بسازید.
2) محتوای این پوشه (index.html و سایر فایل‌ها و پوشه assets) را در ریشه مخزن آپلود کنید.
3) در Settings > Pages، قسمت Build and deployment، گزینه Deploy from a branch را انتخاب کنید.
4) Branch را main و folder را /(root) بگذارید و Save کنید.
5) در بخش Pages نشانی دقیق وب‌سایت نشان داده می‌شود؛ معمولاً شبیه https://USERNAME.github.io/mohammadbagher-portfolio/
6) پس از مشاهده صفحه منتشرشده، آدرس واقعی را برای ساخت QR Code استفاده کنید.

افزودن تصاویر واقعی:
- پس از دریافت رضایت لازم از دانش‌آموز و ولی/مدرسه، عکس‌ها را در assets/photos قرار دهید.
- فایل content.js را با ویرایشگر متن باز کنید و داخل photos مواردی مانند این اضافه کنید:
  { src: 'assets/photos/photo1.jpg', title: 'مراسم ایام فاطمیه', alt: 'تصویر فعالیت فرهنگی' },
- برای فیلم، فایل را در assets/videos بگذارید و در videos اضافه کنید:
  { src: 'assets/videos/video1.mp4', title: 'فیلم مراسم' },
- در بخش activities می‌توانید هر فعالیت دیگر را در آینده ثبت کنید.
- اگر فایل فیلم حجیم باشد، از روش مناسب میزبانی ویدئو استفاده کنید؛ فایل‌های بزرگ ممکن است در GitHub محدودیت داشته باشند.

ساخت QR Code پس از انتشار:
- از ترمینال کامپیوتری که Python و بسته qrcode نصب دارد اجرا کنید:
  pip install 'qrcode[pil]'
  python make_qr.py https://YOUR-REAL-PUBLISHED-URL/
- تصویر qr-code.png ساخته می‌شود و می‌توان آن را در تقدیرنامه قرارداد.
- با ثابت ماندن آدرس سایت و افزودن عکس‌ها یا افتخارات جدید، QR Code تغییر نمی‌کند.

حریم خصوصی:
- این صفحه در حالت پیش‌فرض برچسب noindex دارد تا از موتورهای جست‌وجو درخواست شود فهرستش نکنند؛ این به‌معنی خصوصی یا رمزدار بودن صفحه نیست.
- هر فردی که نشانی یا QR را داشته باشد می‌تواند محتوای منتشرشده را ببیند.
- اطلاعات حساس، آدرس، شماره تماس و جزئیات شخصی دانش‌آموز را منتشر نکنید.
- برای دسترسی محدود واقعی باید از یک سرویس دارای احراز هویت استفاده شود.


به‌روزرسانی گالری:
- دو تصویر دریافتی در assets/photos درج شده‌اند.
- فیلم ۲۱ ثانیه‌ای برای نمایش بهتر روی موبایل با حجم کمتر در assets/videos قرار گرفته است.
- برای انتشار عمومی، رضایت دانش‌آموزان حاضر در عکس‌ها و فیلم و مجوز مدرسه را بررسی کنید.
- QR Code واقعی فقط پس از انتشار سایت و مشخص شدن نشانی اینترنتی آن قابل ساخت است.
